Анатомия CSS-правил

Введение

CSS (Cascading Style Sheets) позволяет отделить содержимое от оформления. Каждое правило состоит из селектора и блока объявлений в фигурных скобках.

Блочная модель и наследование

Селекторы могут быть по тегу, классу, id или атрибуту. Комментарии в CSS полезны для пояснения сложных моментов.

На этой странице мы используем только селекторы по тегам: body, h1, h2, p, a. Каждое правило содержит минимум три свойства.
