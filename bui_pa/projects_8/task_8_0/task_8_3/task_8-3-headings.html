Введение в веб-разработку

Курс знакомит с основами создания веб-сайтов: структура HTML, стилизация CSS и базовое программирование на JavaScript.

1. Основы HTML

Теги, атрибуты, заголовки, параграфы, списки и ссылки — каркас страницы.

1.1 Структура HTML-документа

DOCTYPE, html, head, body — разберём, как строится любой веб-документ и для чего нужны эти части.

1.2 Работа с текстом и списками

Форматирование текста, создание маркированных списков, а также цитирование.

1.3 Вставка изображений и ссылок

Добавление картинки с атрибутом alt и создание гиперссылки для навигации между страницами.

2. Основы CSS

Стили: селекторы, цвета, шрифты, отступы и рамки для улучшения внешнего вида страниц.
